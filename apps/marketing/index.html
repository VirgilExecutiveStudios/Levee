Verify Educational Concepts with Precision

Levee is an automated agent that rigorously verifies, fact-checks, and grounds information against live web data from authoritative educational sources — ensuring accuracy and reliability.

What Levee IS vs. What It Isn't

✅ WHAT LEVEE IS

  • An Automated Verification Agent
  • Real-time Web Grounding Engine
  • Multi-LLM Fact-Checking System
  • Human-in-the-Loop Review Framework
  • Persistent Storage with Citations
  • Extensible Architecture for Educational Data

❌ WHAT LEVEE ISN'T

  • A Simple Search Bar or Scraper
  • A Static Content Parser
  • A Basic Keyword Matcher
  • A Manual Fact-Checking Tool
  • A Standalone Database Query
  • A Generic AI Chatbot

How Levee Works

🔍

Web Grounding

Levee automatically searches authoritative educational domains (OpenStax, Khan Academy, NCES, Britannica, etc.) to find verifiable sources for any educational concept.

🤖

AI Verification

Using state-of-the-art LLMs via LiteLLM, Levee compares source information with the original claim to compute confidence scores and provide detailed reasoning for every verification.

👥

Human-in-the-Loop

Low-confidence results (<85%) are automatically flagged for expert review, ensuring educational integrity while leveraging AI efficiency for high-confidence verifications.

Download & Setup Guide

Choose your platform below for step-by-step installation instructions. Levee supports all major operating systems and architectures.

🍎 macOS (Apple Silicon & Intel)

Option 1: Homebrew (Recommended)

brew install Virgil/homebrew-levee/levee

Option 2: Direct Download

curl -sSL https://get.levee.virgil/macos/levee-latest.dmg -o levee.dmg
open levee.dmg
drag Levee to Applications folder

💻 Windows 11/10 (x64 & ARM64)

Option 1: Winget

winget install Virgil.Levee

Option 2: MSI Installer

curl -sSL https://get.levee.virgil/windows/levee-latest.msi -o levee.msi
start /wait levee.msi /quiet

🐧 Linux (Debian, Ubuntu, RHEL, etc.)

Package Manager (APT/YUM)

# Debian/Ubuntu
echo "deb [signed-by=/usr/share/keyrings/levee-archive-keyring.glass] https://repo.levee.virgil/linux/ $(lsb_release -cs) main" > /etc/apt/sources.list.d/levee.list
curl -sSL https://repo.levee.virgil/linux/levee-archive-keyring.glass -o /usr/share/keyrings/levee-archive-keyring.glass
apt update && apt install levee

Standalone Binary

curl -sSL https://get.levee.virgil/linux/levee-latest-x86_64.AppImage -o levee.AppImage
chmod +x levee.AppImage
./levee.AppImage

🐳 Docker & Containerized

Docker Hub

docker pull virgilventures/levee:latest
docker run -p 8000:8000 -v levee-data:/app/data virgilventures/levee:latest

Quick Verification Test

After installation, try verifying a concept right from your terminal or local app:

levee verify "Pythagorean Theorem" --subject Mathematics --grade-level 8
